🎯 YOUR 3-STEP DEPLOYMENT PROCESS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  STEP 1: Upload to cPanel
  ───────────────────────────────
  Upload to: public_html/
  Files:
    • backend/
    • frontend/dist/
    • node_modules/
    • package.json
    • .htaccess
    • All other files

  STEP 2: Configure Database
  ───────────────────────────────
  In cPanel:
    1. MySQL Databases → Create new database
    2. Create user and note credentials
    3. Grant ALL privileges
    4. Update backend/.env with credentials

  STEP 3: Setup Node.js in cPanel
  ───────────────────────────────
  In cPanel:
    1. Setup Node.js App → Create Application
    2. Node.js version: 18+
    3. Startup file: backend/index.js
    4. Port: 8080
    5. Add environment variables
    6. Click "Restart App"

  ✓ DONE! Visit https://yourdomain.com
